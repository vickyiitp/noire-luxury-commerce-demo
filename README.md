## 🌟 Highlights

- 🕶️ **Photorealistic 3D Product Configurator**: Inspect luxury watches and jewelry with real-time environment maps, HDR reflections, and metalness adjustments.
- ⚡ **React Three Fiber & Drei Pipeline**: Declarative WebGL component hierarchy for smooth 60 FPS rendering.
- 🎨 **Minimalist Haute Couture Design System**: Tailored typography, deep black palettes, and subtle micro-interactions.

## 🛠️ Stack & Setup

- `@react-three/fiber` & `@react-three/drei`
- `Three.js`, WebGL Canvas
- Next.js 15, TypeScript, TailwindCSS

```bash
git clone https://github.com/vickyiitp/noire-luxury-commerce-demo.git
cd noire-luxury-commerce-demo
npm install
npm run dev
```
